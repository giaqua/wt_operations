# Request for Proposal

## Purpose
Formal RFP response management for WWTP projects, tracking customer RFPs and coordinating proposal responses.

## Key Fields
- Customer, RFP Number, RFP Date, Submission Deadline, Evaluation Criteria, RFP Status, Priority

## Common Tasks
1. Create RFP with customer details
2. Link to Customer Proposal
3. Set submission deadline and criteria
4. Track evaluation status
5. Handle customer questions

## Permissions
- System Manager: Full access
- Site Manager: Full access  
- Operations Manager: Full access
- Account Manager: Full access
- Operations Technician: Read only
