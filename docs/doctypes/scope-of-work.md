# Scope of Work

## Purpose
Master data defining standardized work packages and responsibilities for WWTP projects.

## Key Fields
- Scope Name, Description, Work Package, Responsible Party, Not Required, Remarks

## Common Tasks
1. Create scope definitions
2. Define work packages
3. Assign responsibilities
4. Set requirements
5. Use in Technical Questionnaires

## Permissions
- System Manager: Full access
- All other roles: Read only
