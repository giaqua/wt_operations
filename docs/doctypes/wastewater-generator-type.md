# Wastewater Generator Type

## Purpose
Master data classifying different types of wastewater sources for WWTP projects.

## Key Fields
- Generator Type Name, Description, Characteristics, Treatment Requirements, Compliance Standards

## Common Tasks
1. Create generator type definitions
2. Define characteristics
3. Set treatment requirements
4. Specify compliance standards
5. Use in Technical Questionnaires

## Permissions
- System Manager: Full access
- All other roles: Read only
