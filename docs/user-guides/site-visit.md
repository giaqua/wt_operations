# User Guide: Site Visit

## What this is
Record the on-site assessment: conditions, measurements, risks, and recommendations.

## When to use
- From a submitted Site Visit Request
- Ad-hoc visits that need documentation

## Quickstart (3–5 minutes)
1. Site Visit → New, link `related_site_visit_request`
2. Click “Auto-fill from SVR” to pull contact/location and plan
3. Set `date`, `visit_by`, and update `visit_status` as you progress
4. Fill sections:
   - Site Information (address, geolocation)
   - Facility Assessment (existing_treatment, capacity)
   - Technical (wastewater_source, discharge_point, effluent_standards)
   - Site Conditions (site_accessibility, power_availability, ground_conditions)
   - Sampling (toggle `samples_collected`, add samples if relevant)
   - Documentation (photos/sketches/measurements flags)
5. Click “Calculate Risk Level” to set `risk_level` and note risks
6. Add `recommendations` and `next_steps`
7. Submit (SVR status may auto-update to Completed)

## Buttons
- Auto-fill from STP (TQ): seed site/facility context
- Auto-fill from SVR: bring plan/contact/location
- Calculate Risk Level: derive Low/Medium/High
- Visit Summary: quick printable summary

## Tips
- Add map link and coordinates for repeat visits
- Use photos/sketches to improve clarity for proposal team
- Keep risk notes crisp (cause → impact → mitigation)
