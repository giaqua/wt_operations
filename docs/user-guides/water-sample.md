# User Guide: Water Sample

## What this is
Manage collection and handling of water samples for lab analysis.

## When to use
- During/after a Site Visit
- Routine monitoring or compliance checks

## Quickstart (2–4 minutes)
1. Water Sample → New, link `site_visit`
2. Click “Auto-fill from Site Visit” (optional) to bring context
3. Set basics:
   - `sample_tag` (unique), `sample_date`, `sample_type` (Influent/Effluent/Process)
   - `collection_location`, `collection_method`, `sample_volume`
4. Preservation & custody:
   - `preservation_requirements`, `chain_of_custody`
   - Storage: `storage_location`, `storage_temperature`, `expiry_date`
5. Notes / special instructions for lab
6. Submit

## Tips
- Use consistent `sample_tag` naming (e.g., <SV>-<YYYYMMDD>-E1)
- Record preservation method and temperature to avoid invalidation
- Attach photos when sampling points are hard to find
