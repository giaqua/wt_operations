# User Guide: WWTP Technical Proposal

## What this is
The comprehensive technical solution: treatment technology, process design, implementation plan, risks, and costs—built from assessments and sampling.

## When to use
- After TQ (and preferably Site Visit and Water Sample) are ready
- To brief customer or internal stakeholders on the proposed solution

## Quickstart (4–6 minutes)
1. WWTP Technical Proposal → New, link `wwtp_technical_questionnaire`
2. Click “Auto-fill from TQ” to seed project details, specs, roles
3. (Optional) Link `site_visit` and click “Auto-fill from Site Visit”
4. (Optional) Link `water_sample` and click “Auto-fill from Water Sample”
5. Complete specs:
   - `treatment_technology`, `process_description`, `treatment_stages`
   - Implementation timeline: `design_period`, `procurement_period`, `construction_period`, `commissioning_period` → system totals
6. Costs:
   - `equipment_cost`, `civil_works_cost`, `electrical_cost` → verify `total_project_cost`
7. Risks & recommendations:
   - `technical_risks`, `environmental_risks`, `mitigation_strategies`, `technical_recommendations`, `next_steps`
8. (If needed) “Sync to External Site” to share with partner site
9. Submit

## Buttons
- Auto-fill from TQ / Site Visit / Water Sample
- Generate Proposal Summary
- Sync to External Site

## Tips
- Ensure timelines match procurement reality; update immediately when scope changes
- Keep risk items short and action-oriented
- Double-check units and capacities copied from assessments
