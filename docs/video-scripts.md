# Video Scripts for WT Operations DocTypes

## Script 1: WWTP Technical Questionnaire

### Introduction (0-30 seconds)
"Welcome to the WT Operations module. Today I'll show you how to use the WWTP Technical Questionnaire, which is the foundation document for all wastewater treatment plant projects. This document captures project requirements, site conditions, and technical specifications."

### Screen Recording Steps (30 seconds - 5 minutes)

**Step 1: Creating a New Technical Questionnaire**
"Let's start by creating a new Technical Questionnaire. I'll navigate to WT Operations and click on WWTP Technical Questionnaire, then click 'New'."

**Step 2: Basic Information**
"First, I'll fill in the basic information. I need to select a Lead from the dropdown - this links to our CRM system. I'll also select an Opportunity if available, and set the assessment date."

**Step 3: Project Details**
"Now I'll enter the project details. I'll select the wastewater generator type - this could be domestic, industrial, slaughterhouse, or other types. I'll enter the required capacity in cubic meters per day."

**Step 4: Effluent Quality Auto-Population**
"Here's a key feature - the effluent quality auto-population. When I select the target effluent type, the system automatically populates all the effluent quality parameters based on regulatory standards. Let me select 'Irrigation (unrestricted)' and you'll see how all the parameters are automatically filled."

**Step 5: Site Information**
"I'll add site information including the available footprint, location requirements, existing equipment, and site conditions. This helps our technical team understand what we're working with."

**Step 6: Influent Streams**
"Another automation feature - when I set the number of streams, the system automatically creates rows in the influent stream table. I'll set it to 2 streams and you'll see the table populate."

**Step 7: Roles and Responsibilities**
"The system also auto-populates roles and responsibilities from our master data. This ensures consistency across all projects and helps define who's responsible for what."

**Step 8: Site Visit Requirements**
"I'll check the boxes for site visit required and sample collection required if needed. This will trigger downstream processes."

**Step 9: Custom Buttons**
"Notice the custom buttons here. The 'Create Site Visit Request' button will create a formal site visit request. The 'Refresh Effluent Parameters' button allows me to re-populate the effluent parameters if needed."

**Step 10: Submission**
"Finally, I'll review all the information and submit the document. Once submitted, it becomes available for creating site visit requests and technical proposals."

### Conclusion (5-6 minutes)
"The WWTP Technical Questionnaire is the starting point for all our projects. It captures essential project information and uses automation to ensure consistency and accuracy. The auto-population features save time and reduce errors, while the custom buttons streamline the workflow to the next steps."

## General Recording Tips

### Before Recording
1. **Prepare Test Data**: Have sample records ready for each DocType
2. **Clear Browser**: Clear browser cache and close unnecessary tabs
3. **Screen Resolution**: Use appropriate screen resolution for recording
4. **Audio Check**: Test microphone and audio levels

### During Recording
1. **Speak Clearly**: Enunciate clearly and maintain consistent pace
2. **Show Cursor**: Ensure cursor movements are visible
3. **Pause for Processing**: Allow time for page loads and data processing
4. **Highlight Features**: Use cursor to highlight important features
5. **Explain Actions**: Explain what you're doing as you do it

### After Recording
1. **Review Footage**: Check audio quality and screen clarity
2. **Edit if Needed**: Trim unnecessary pauses or errors
3. **Add Captions**: Consider adding captions for accessibility
4. **Test Playback**: Ensure video plays correctly on target devices
